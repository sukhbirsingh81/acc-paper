\Title{Service-Oriented 4D Path Planning for Structured Corridor Operations within U-space: Planner-Stage Scaling and Conflict-Driven Lateral Re-Routing}

\Author{Sukhbir Singh $^{1,2,}$*, Enno Nagel $^{2}$ and Bianca Isabella Schuchardt $^{2}$}
\AuthorNames{Sukhbir Singh, Enno Nagel and Bianca Isabella Schuchardt}

\address{%
$^{1}$ \quad Technical University of Munich (TUM), Germany\\
$^{2}$ \quad DLR Institute of Flight Guidance, Germany}

\corres{Correspondence: please add corresponding author email address}

\abstract{Urban air mobility requires scalable path-planning and conflict-management services for structured low-altitude operations. This paper presents a service-oriented four-dimensional path-planning framework for preparing candidate operation intent within U-space. The framework combines graph-based shortest-path routing, flight-management-based trajectory generation, multi-dimensional conflict checking, and request-local lateral re-routing. Its architecture separates topology provision, route planning, waypoint synthesis, trajectory generation, deconfliction, and a U-space Service Provider-facing authorisation boundary into distinct responsibilities. The prototype is evaluated on a Hamburg vertiport corridor network using two sequential local experiments. In a planner-stage scaling experiment with deconfliction disabled, path search and waypoint synthesis remain sub-millisecond, while CFMS trajectory generation dominates runtime and explains the observed scaling with selected path distance. In a preliminary conflict-resolution-enabled experiment with 100 sequential operator requests, all 100 candidate trajectories are retained as locally deconflicted plans: 93 are conflict-free on the first deconfliction check, one has no peer trajectory, and six are resolved by lateral re-routing. No request reaches the configured retry limit and no routing errors occur. The results provide a baseline evaluation of candidate trajectory preparation before operational USSP authorisation and should not be interpreted as an operational capacity assessment.}

\keyword{urban air mobility; U-space; Drones; four-dimensional trajectory planning; path planning; deconfliction; microservices; A* search; CFMS; NDMap}

\renewcommand{\addhighlights}{%
\noindent\textbf{What are the main findings?}
\begin{itemize}[labelsep=2.5mm,topsep=-3pt]
\item A service-oriented U-space planning prototype separates route planning, waypoint synthesis, 4D trajectory generation, and NDMap-based deconfliction.
\item In the evaluated Hamburg corridor benchmark, CFMS trajectory generation dominates planner-stage runtime, while A* path search and waypoint synthesis remain below one millisecond.
\end{itemize}\vspace{3pt}
\textbf{What are the implications of the main findings?}
\begin{itemize}[labelsep=2.5mm,topsep=-3pt]
\item Lateral route alternatives can be searched quickly, but repeated 4D trajectory generation is the main cost of conflict-driven re-planning.
\item The evaluated results are a local sequential baseline for a prototype, not an operational capacity assessment.
\end{itemize}}
